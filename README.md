# Sistema de Controle de Estoque

## 📖 Descrição

Este é um sistema de linha de comando (CLI) para o controle de estoque de uma loja de eletrônicos, desenvolvido como projeto para a disciplina de **Lógica Computacional** na faculdade UniFECAF. O objetivo é aplicar conceitos de lógica de programação em um cenário prático.

Desenvolvido em Python, o projeto oferece uma solução simples para gerenciar produtos, permitindo adicionar, atualizar, excluir e visualizar itens em estoque.

Também tem alguns detalhes a mais como a utilização de cores no terminal para melhorar a experiência do usuário.

---

## ✨ Funcionalidades

O sistema oferece as seguintes funcionalidades:

- **Adicionar Produto**: Permite cadastrar um novo produto no estoque, solicitando nome, preço e quantidade. O sistema valida os dados para garantir a consistência das informações.
- **Atualizar Produto**: Modifica as informações de um produto já existente (funcionalidade em desenvolvimento).
- **Excluir Produto**: Remove um produto do estoque (funcionalidade em desenvolvimento).
- **Visualizar Estoque**: Exibe uma lista de todos os produtos cadastrados, com seus respectivos detalhes (funcionalidade em desenvolvimento).
- **Interface Colorida**: Utiliza cores no terminal para diferenciar mensagens de sucesso, erro, títulos e opções do menu, melhorando a usabilidade.

## 🚀 Como Executar

Para executar o sistema, você precisa ter o Python 3 instalado em sua máquina. Siga os passos abaixo:

1.  **Clone o repositório** (ou baixe os arquivos):
    ```bash
    git clone https://github.com/kayooliveira/case-computational-logic.git
    ```

2.  **Navegue até o diretório do projeto**:
    ```bash
    cd case-computational-logic
    ```

3.  **Execute o script principal**:
    ```bash
    python controle_estoque.py
    ```

Após a execução, o menu principal do sistema será exibido no terminal, e você poderá interagir com as opções disponíveis.
